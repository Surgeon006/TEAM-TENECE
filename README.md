
VitaTrack is a hospital billing and collections management web application designed to help healthcare organizations monitor billing activity, manage claims, track overdue payments, and review financial performance from a centralized dashboard.

## 📌 Overview

VitaTrack provides a clean, dashboard-focused interface for hospital billing teams. The system is designed around the workflow of monitoring claims, identifying outstanding payments, reviewing department-level billing activity, and generating useful reports.

The current interface includes onboarding and authentication screens, a billing dashboard, department management, work queue/claims management, claim details, and reporting.

## ✨ Features

### Authentication & Onboarding
- Onboarding/welcome screen
- User sign-up
- User sign-in
- Clean and simple authentication flow

### Dashboard
The main dashboard gives users a quick overview of billing and collections performance.

It includes:
- Total billed amount
- Pending/unresolved claims
- Resolved claims
- Overdue claims
- Insurance claims currently processing
- Billing by department doughnut chart
- Claim status overview doughnut chart
- Top overdue claims table
- Date and filter controls
- Quick access to reports

### Departments
The Departments section provides a view for organizing and monitoring billing information by hospital department.

Examples of departments represented in the interface include:
- Oncology
- Cardiology
- Neurology
- Orthopedics
- General Surgery
- Other departments

### Work Queue
The Work Queue is intended to help billing staff monitor claims and prioritize outstanding work.

It provides a central place for claims that may require:
- Review
- Follow-up
- Processing
- Resolution

### Claim Details
The claim details interface provides more information about individual claims, allowing users to inspect claim-related information and status.

### Reports
The Reports section provides access to billing and claims data in a more detailed format for monitoring and analysis.

### Responsive Interface
The interface is being designed to work across:
- Desktop
- Laptop
- Tablet
- Mobile devices
